# Attention sidebar

Свой список тредов для сайдбара bb (плагин `attention-sidebar`, слот
`app.slots.experimental_threadList`).

Сверху вниз: **Ждут вас** (вопросы `?`, ошибки `!`, готовые `✓` из всех
проектов), **В работе**, **Закреплённые**, затем папки проектов с аватаром,
названием и счётчиком. Иконок провайдеров нет: в верхних блоках у строки
аватар проекта (буквы из названия, цвет из FNV-1a от `projectId`).

## Вложенность и сортировка

- Возьмите мышью строку треда и перетащите её на строку будущего родителя. Связь сохраняется в bb. Если оба треда в одной папке, дочерний
  появится с отступом. В верхних блоках и при отображении в разных папках
  рядом с дочерним тредом показано название родителя.
- Чтобы вернуть дочерний тред на верхний уровень, перетащите его на заголовок
  папки его проекта.
- Стрелка рядом с родительским тредом в папке сворачивает или раскрывает его
  ветку. BB запоминает состояние каждой ветки в текущем клиенте.
- Раскройте папку проекта и нажмите ↕, чтобы выбрать порядок тредов.
  По умолчанию сверху последние обновлённые. Также можно выбрать порядок
  по последнему открытию, времени создания или названию. Родитель остаётся
  перед дочерними тредами при любом порядке.
- Выбор порядка для каждой папки и история открытий сохраняются в хранилище
  текущего браузера или приложения bb. В режиме «По последнему открытию»
  треды без записанного открытия идут ниже, в порядке последней активности.

## Структура

- `app.tsx` — регистрация слота.
- `components/` — React: список, строка, аватар, хуки (таймер, заморозка
  активного треда, свёрнутость в localStorage).
- `lib/` — чистая логика: `model.ts` (классификация и группировка),
  `avatar.ts`, `time.ts`.
- `server.ts` — пустой бэкенд: манифест bb требует `bb.server`.
- `skills/attention-sidebar/SKILL.md` — что делает плагин и как вернуть стандартный
  список.

## Команды

```sh
npm install --include=dev
npm test               # vitest: lib + смоук renderSlot
npx tsc --noEmit
bb plugin build
bb plugin install . --yes
```

Вернуть стандартный список: Settings → Appearance → Sidebar thread list →
Thread list, или `bb plugin disable attention-sidebar`.
